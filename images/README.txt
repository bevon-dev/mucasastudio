Put your artwork photos here, named to match js/main.js:
  image1.jpg, image2.jpg, image3.jpg, image4.jpg, image5.jpg, image6.jpg

Until a file is added, that spot on the site shows a placeholder
pattern with the missing filename, so nothing looks broken.

To add a 7th (or more) piece: open js/main.js and add another object
to the ARTWORKS array at the top, following the same pattern.
